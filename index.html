SaaSWeaveThe operational layer of a SaaS, already wired.

A production-oriented, multi-tenant SaaS starter built as a full-stack TypeScript monorepo. Workspaces, auth, billing, background jobs, observability, and typed APIs behind one application boundary.

Quick start
Introduction
Product tour
🏢

Workspace tenancy

Member roles, invitations, profiles, and organization switching, with tenant-scoped data access enforced in the API layer.

🔐

Authentication and SSO

Email/password, OAuth provider discovery, 2FA, SSO/SAML, sessions, and an impersonation policy, built on Better Auth.

💳

Billing that reconciles

Stripe checkout, portal, ordered webhook handling, subscriptions, usage attribution, and MRR snapshots.

⚙️

Background processing

BullMQ workers for email, notifications, webhooks, Stripe, data exports, batch jobs, and scheduled work.

📊

Observability built in

Structured logs, Prometheus metrics, health and readiness probes, retention jobs, and backup verification tooling.

🧩

One typed boundary

TanStack Start, Hono, and oRPC give the web app, API, and workers a single end-to-end typed contract.

Platform administration ​

A typed API, documented ​

With ENABLE_OPEN_API_DOCS=true, the server exposes an interactive Scalar reference generated from the same typed contract the clients use.

Most integrations are environment-gated. Stripe, OAuth, external email delivery, OpenAPI docs, metrics, and the local SAML identity provider stay off until you configure them, so the default stack runs without external credentials.
